# Gärtnerei Josef Brunner – Immersive Studio Edition v4.0

> **Kinoreife High-End Website für meisterliche Pflanzenkultur in Regensburg**  
> Konzipiert, gestaltet und entwickelt nach den Gesetzen des *Website Generator Studio V4.0*.

---

## 🌟 Highlights & Features

- **Immersive 3D Scrollytelling:** Scroll-gekoppelte Explosionsdarstellung (*Botanical Layer Exploded View*) in Three.js (WebGL). Visualisiert Wurzelfundament, poröse Drainage, nährstoffreiches Gärtnersubstrat und vitale Blütenkronen mit Partikeleffekten.
- **Eiserne Mobile-Responsiveness (Zero-Collision):** Schutz vor Touch-Fallen auf Smartphones (`pointer-events: none` auf dem 3D-Canvas während des Scrolls), feste mobile Bottom-Bar mit Z-Index 99999.
- **Scroll-Physik auf Staff-Engineer-Niveau:** Lenis Smooth Scroll synchronisiert via `gsap.ticker` mit `lagSmoothing(0)`, `scroll-behavior: auto !important` (kein Ruckeln auf macOS/Windows Trackpads).
- **100% Deutscher Rechtscheck (§ 5 DDG & DSGVO Art. 13):** Rechtssichere Modals, Two-Click Google Maps mit `data-src` und TDDDG-konformes Consent-Banner mit gleichwertigem „Nur notwendige“-Button.
- **Interaktiver Regensburger Bepflanzungsrechner:** Berechnet dynamisch Pflanzenanzahl, Substratvolumen in Litern und Schätzkosten für Balkonkästen, Staudenbeete, Gemüse und Grabpflege.
- **3-Stufen Anfrage-Funnel:** Hohe Conversion-Rate mit Validierung, Fortschrittsbalken und DSGVO-Checkbox.

## 🚀 Lokaler Start

### Windows:
Doppelklick auf `start.bat` oder im Terminal:
```cmd
start.bat
```

### macOS / Linux:
```bash
chmod +x start.sh
./start.sh
```

Alternativ einfach `index.html` direkt im Webbrowser öffnen.

## 🛠️ Tech-Stack

- **HTML5 & Vanilla JavaScript:** Keine Framework-Abhängigkeiten, sofort einsatzbereit.
- **Tailwind CSS (CDN):** Maßgeschneiderte Farbpalette (*Forest, Terracotta, Gold, Sage*).
- **Three.js (WebGL):** 3D-Bühne mit PBR-Materialien und Visibility Culling (0% GPU-Last außerhalb der 3D-Sektion).
- **GSAP & ScrollTrigger:** Butterweiche Animationen und Textschritt-Wechsel.
- **Lenis Smooth Scroll:** Natürliches Trägheits-Scrolling.
